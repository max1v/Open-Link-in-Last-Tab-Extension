# Privacy Policy for Open in Last Tab

**Last updated:** July 24, 2026

This extension does not collect, store, transmit, or share any personal data or browsing information.

## Permissions Used

- **`contextMenus`** — Used solely to add the "Open in Last Tab" item to the browser's right-click context menu on links.
- **`tabs`** — Used solely to count how many tabs are open in the current window so the new tab can be placed at the very end of the tab strip.

## Data Handling

- No user data is collected, logged, or stored.
- No data is sent to any remote server.
- No cookies, analytics, or tracking mechanisms are used.
- The extension only processes the URL of the link you right-click, and only at the moment you use the context menu action.
